The OV5640 autofocus microcode, which lets the PinePhone's rear camera focus. Without it the camera works with fixed
focus.

The file is OmniVision's and comes with no licence. It is downloaded unmodified from its upstream copy
(https://github.com/pmsourcedump/ov5640), the way the PinePhone Linux distributions ship it. It will be removed if the
copyright holder asks.
